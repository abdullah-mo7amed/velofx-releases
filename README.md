## Core Capabilities

### 1. Intelligent Cache Management
- **Safe Junk Cleaner:** Clears corrupted shader files, crash dumps, and stale logs without affecting saved game progress.
- **Per-Server Cache Cleaner:** Target and purge cache files for individual FiveM servers to reclaim disk space without re-downloading entire assets.

### 2. Engine & Performance Profiles
- **RAGE Engine Presets:** Distance culling and detail LOD scalers tailored specifically for heavy RP cities and pursuits.
- **Standby Memory Purger:** Flushes Windows standby memory pools to eliminate micro-stutters during high-speed driving.
- **High CPU Priority:** Directs processor scheduling towards FiveM execution.

### 3. Network & Connection Diagnostics
- **Gaming DNS Presets:** Quickly apply Cloudflare (1.1.1.1) or Google (8.8.8.8) gaming DNS configurations.
- **Latency & Packet Health:** Real-time round-trip latency checks and packet health tests to FiveM edge gateways.
- **Discord IPC Repair:** Resolves "Checking Discord" connection hangs with a single click.

### 4. RP Tools & Configuration Backups
- **Config Locker:** Backup and restore your fivem.cfg and gta5_settings.xml configurations.
- **Rockstar & Steam Auth Fixer:** Clears stale entitlement tickets and stuck launcher processes.
